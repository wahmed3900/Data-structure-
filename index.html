What is a data structure? A way to organize information so a program can use it. Think of a shopping list, a filing cabinet, or a line at the bank. Each one is good at different jobs.

What is Big O? A way to say how much slower something gets as you add more stuff. O(1) means instant at any size, like grabbing the first item on a list. O(n) means you might check every item, like asking each person in a line. O(log n) means you cut the work in half each step, like a "higher or lower" guessing game.
